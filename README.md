## Auth Service (gRPC + JWT)

Сервис аутентификации и авторизации пользователей, реализованный на Go с использованием gRPC, PostgreSQL и JWT. Предназначен для использования в микросервисной архитектуре.

##Стек технологий

- Go (Golang)

- gRPC (Protocol Buffers)

- PostgreSQL

- JWT (JSON Web Token)

- Docker / Docker Compose

- SQL миграции
Функциональность

- Регистрация пользователей

- Аутентификация пользователей

- Генерация JWT-токенов

- Проверка и валидация токенов

- Хранение пользователей и сессий в PostgreSQL

- Работа с миграциями базы данных

- Взаимодействие сервисов через gRPC
## Архитектура

Проект построен с разделением на слои:

- api/internal/grpc — gRPC сервер и обработка запросов

- api/internal/services — бизнес-логика

- api/internal/storage — работа с базой данных

- api/internal/domain — модели данных

- api/internal/lib/jwt — работа с JWT

- api/internal/config — конфигурация

Основные принципы:

разделение ответственности

изоляция бизнес-логики

расширяемая структура проекта

Структура проекта

api/

cmd/sso/ — точка входа

internal/ — основная логика приложения

proto/ — описание gRPC API

migrations/

SQL-миграции для создания таблиц

docker-compose.yaml — запуск сервиса и БД

## Запуск проекта
Запуск через Docker

docker-compose up --build

Применение миграций

Миграции находятся в папке migrations/ и применяются при запуске или вручную через инструмент миграций.
## gRPC API

Сервис описан через Protocol Buffers (proto/sso.proto).

Основные методы:

- Register — регистрация пользователя

- Login — аутентификация пользователя

- ValidateToken — проверка JWT

## Конфигурация

Настройки задаются в api/config/local.yaml:

- параметры подключения к базе данных

- настройки сервера

- JWT секрет
